# English with Tobo & Lulu

Official website for **English with Tobo & Lulu** — short, friendly English videos for little learners aged 2–6, set at Little Stars Kindergarten.

**Live site:** https://shahz-bot1.github.io/tobo-and-lulu/
**YouTube:** https://www.youtube.com/@ToboAndLulu

## What's on the site

- **Home** — meet Tobo & Lulu, what we learn, word of the day, and tips for parents
- **Videos** — watch our episodes, including *Meet Tobo & Lulu* and *Lulu's Taste Challenge*
- **Shop** — Tobo & Lulu merchandise (currently sold out)

The site is a single static page (`index.html`) with all images inlined, so it can be dropped into any static host.
